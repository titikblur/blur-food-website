Privacy Policy

Last updated: September 5, 2026

Data Collection

Blur Food's Comment Scraping Tool collects the following data from social media platforms:

  • TikTok: Comment text, username, avatar URL, timestamp (parsed from saved HTML files)
  • YouTube: Comment text, author name, avatar URL, timestamp (via YouTube Data API v3)
  • Instagram: Comment text, username, timestamp (via Instagram Graph API)

Data Usage

Collected data is used solely for content analysis and research purposes by the account owner. Data is not shared with third parties, sold, or used for advertising.

Data Storage

All data is stored locally on the user's device. No data is transmitted to external servers. The tool operates entirely offline (except for API calls to YouTube and Instagram, which are made directly from the user's device).

Data Deletion

Users can delete all collected data at any time by removing the local files generated by the tool (CSV and JSON files in the output directory).

Third-Party Services

This tool interfaces with the following third-party APIs:

  • YouTube Data API v3 - Used to fetch comments from YouTube videos. Subject to Google's Privacy Policy.
  • Instagram Graph API - Used to fetch comments from Instagram posts. Subject to Meta's Privacy Policy.

Security

API keys and access tokens are stored locally in environment files (.env) and are never transmitted to external servers. The tool runs entirely on the user's local machine.

Changes to This Policy

We may update this Privacy Policy from time to time. Changes will be reflected in the "Last updated" date above.

Contact

For questions about this privacy policy, contact us at @blur.food on Instagram.
